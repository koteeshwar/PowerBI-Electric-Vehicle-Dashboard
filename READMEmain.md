# **Electric Vehicle Data Analysis Dashboard**



## Project Overview



###### This Power BI dashboard analyzes Electric Vehicle Population Data.



###### **Features**

* &#x20;Total Vehicles KPI
* &#x20;Average Electric Range KPI
* &#x20;Total BEV Vehicles and %
* &#x20;Total PHEV Vehicles and %
* &#x20;Vehicle Registration Trend by Model Year
* &#x20;State-wise Vehicle Analysis
* &#x20;CAFV Eligibility Distribution
* &#x20;Top 10 Vehicle Manufacturers
* &#x20;Top 10 Vehicle Models
* &#x20;Geographical Analysis using Latitude and Longitude
* &#x20;Navigation Buttons between dashboard pages
